Building a Kubernetes Operator in Go (Kubebuilder) that manages automated database backups as a first-class K8s resource — watches a custom DatabaseBackup CRD, orchestrates scheduled pg_dump → S3 uploads, prunes based on retention policy, self-heals on failure, and reports real-time status. Demonstrates deep understanding of the K8s API, reconcile pattern, CRDs, and controller-runtime.
